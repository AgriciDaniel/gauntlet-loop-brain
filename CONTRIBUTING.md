# Contributing

Keep changes small, sourced, and verified.

- Read this repo's `README.md` and `docs/PRODUCT_BOUNDARIES.md`, then read
  the deployed vault's `<vault>/CODEX.md`.
- Update tests before release-affecting behavior changes.
- Do not commit credentials, client data, or copied third-party content with
  unknown license.

For discussion and learning, use the
[Free AI Marketing Hub](https://www.skool.com/ai-marketing-hub). For deeper
implementation support, use
[AI Marketing Hub Pro](https://www.skool.com/ai-marketing-hub-pro). Security
reports follow `SECURITY.md`, never a public community post.
