# Market Research

Baseline retrieved 2026-08-17. Status: buyer and workflow hypotheses are evidence-informed, but willingness to pay and retention are not yet validated.

## Recommended Position

Sell an evidence-gated operating brain for deciding when and how to run ambitious multi-agent refinement, not a magic "one prompt" game builder. The defensible value is a reusable fit gate, decomposition protocol, evaluation stack, run ledger, safety boundary, and honest stopping rule.

## Buyer Hypotheses

| Buyer | Existing materials | Costly problem | Recurring job | Confidence |
|---|---|---|---|---|
| AI Marketing Hub maintainer | skill library, brand and campaign references, QA rubrics, performance data | adapting a promising loop without importing hype, unsafe autonomy, or weak graders | qualify a task, select references, govern a run, review evidence, refresh sources | practitioner |
| Agent workflow or brain author | prompts, tools, memory system, eval fixtures, release gates | turning an exciting prompt pattern into a maintainable and source-cited operating system | maintain canon, run experiments, review claims, package updates | practitioner |
| Product or engineering lead | repository, tests, screenshots, telemetry, architecture contracts | coordinating long-running agent work without regressions, runaway cost, or conflicting edits | decompose, budget, execute, integrate, evaluate, accept | practitioner |
| Creative or marketing operator | competitor artifacts, briefs, style guides, audience evidence, analytics | getting beyond a plausible first draft while retaining taste and human authority | benchmark, build, compare, refine, approve | contested until customer research |

These are product hypotheses, not proof of purchase intent.

## Primary Demand Signals

1. Anthropic's multi-agent research report says the system was useful for valuable breadth-first work and records usage categories including software systems, professional and technical content, business growth strategy, academic work, and organizational research. This supports a broad workflow need, but it is vendor-reported usage, not willingness-to-pay research. S007.
2. Anthropic's agent evaluation guide describes a recurring production problem: without evaluations, teams cannot distinguish regression from noise or verify changes at scale. This supports the need for reusable eval and run evidence. S006.
3. Anthropic's long-running harness work documents incomplete handoffs, context loss, and premature completion declarations. This supports durable state and handoff tooling. S005.
4. The public Claude of Duty repository includes reproducible capture, image-diff, profiling, playtest, and honest-assessment artifacts. This demonstrates that serious runs need much more than the initiating prompt. S002.
5. The named Gauntlet guide and public prompt attracted reuse, but reach and reproduction anecdotes are not independent market validation. S001, S003.

## Economic Boundary

Multi-agent work must clear a high value threshold. Anthropic reports about 15 times chat token usage for its multi-agent research system and warns that shared-context, dependency-heavy domains are poor fits. The multiplier is not a universal forecast, but it makes pre-run value, budget, and stop gates non-negotiable. S007.

The brain should expose costs rather than promise savings:

- estimated and actual token use, spend, wall-clock, and human review time
- number of builders, critics, retries, and integration passes
- improvement per round and regression count
- value of the accepted outcome relative to the simpler baseline

## Alternatives and Differentiation

| Alternative | Where it wins | Brain differentiation |
|---|---|---|
| One strong prompt with retrieval and examples | routine, well-specified, low-risk work | fit gate should recommend this when agentic complexity adds no measured value |
| Fixed workflow or prompt chain | predictable tasks with known steps | Gauntlet Brain handles dynamic decomposition only when justified |
| Standard code review and CI | deterministic software correctness | brain layers references, subjective graders, and long-run evidence without replacing CI |
| Generic multi-agent framework | orchestration primitives | brain supplies evidence policy, coupling decisions, run ledger, critic isolation, and stopping governance |
| Human creative review | nuanced taste and audience judgment | brain prepares traceable candidates and gaps while keeping final authority human |

## Recurring Product Loop

1. Intake the goal, audience, authority, artifact type, references, protected surfaces, and value ceiling.
2. Issue a fit decision: Gauntlet, simpler workflow, or research-first.
3. Build the dependency and coupling map.
4. Select the grader mix and freeze protected acceptance assets.
5. Approve budgets and mutation boundaries.
6. Run, integrate, and record each candidate and regression.
7. Produce an evidence-backed acceptance memo and residual-risk list.
8. Refresh fast-moving sources and convert observed failures into experiments.

## Minimum Viable Paid Proof

Use the preregistered procedure and evidence requirements in
[`docs/MARKET_VALIDATION_PROTOCOL.md`](../docs/MARKET_VALIDATION_PROTOCOL.md).
The templates under `examples/market-validation/` are study instruments, not
completed evidence.

Before claiming paid demand or repeat value, conduct customer discovery and a controlled pilot:

- interview at least five operators in each priority buyer segment using past-work evidence rather than feature reactions
- compare one real task under a simpler baseline and the governed Gauntlet workflow with equal budget
- measure accepted quality, regressions, time, spend, review burden, and operator confidence
- ask for a concrete next commitment, such as a paid pilot, installation, or scheduled second run
- record who declines and why

## Honest Market Conclusion

There is credible evidence for the underlying operational problems and for iterative agent workflows. There is not yet primary evidence that buyers will pay for this specific brain, that it improves outcomes at equal budget, or that it creates recurring retention. Market-ready claims remain unavailable until those tests are run.
