# Effective harnesses for long-running agents

## What It Says

- Long-running work needs explicit state artifacts and clean handoffs across context windows.
- Compaction alone was insufficient in Anthropic's application-building experiments.
- Attempting too much at once and later declaring incomplete work done were observed failure modes.
