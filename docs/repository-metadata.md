## Release Names

- Stable tag: `vMAJOR.MINOR.PATCH`
- Prerelease tag: `vMAJOR.MINOR.PATCH-rc.N`
- First planned prerelease: `v0.1.0-rc.1`
- First planned stable release: `v0.1.0`

A release tag must identify one reviewed clean commit and its matching manifest,
checksums, notes, and license. An experimental release never implies market
readiness.
